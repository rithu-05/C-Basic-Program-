# ATM Management System in C

## About the Project
This is my first GitHub repository, created as part of my C programming learning journey. The project is a simple console-based ATM Management System developed using the C programming language.

It allows users to perform basic ATM operations through a menu-driven interface.

## Features
- Four-digit password format validation
- Maximum of three login attempts
- Withdraw money
- Check account balance
- Deposit money
- Display the updated balance after transactions
- Optional receipt display
- Exit the ATM system

## Technologies Used
- Programming Language: C
- Header File: `stdio.h`
- Concepts: Variables, data types, `while` loop, `do-while` loop, `if-else`, `switch-case`, user input and output, and arithmetic operations.

## Initial Balance
The initial account balance is ₹10,000.

## How to Run
1. Clone or download this repository.
2. Open `main.c` in a C compiler or IDE.
3. Compile and run the program.
4. Follow the instructions displayed in the terminal.

### Compile using GCC
```bash
gcc main.c -o atm
```

### Run the program
```bash
./atm
```

On Windows, run:
```bash
atm.exe
```
